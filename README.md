<h1 align="center">
  📖 Biblioteca Virtual
</h1>

## 🚀 Sobre o projeto

Este projeto foi desenvolvido para a **escola** com o objetivo de praticar conceitos de **JavaScript**, além de aplicar conhecimentos em **CSS (estilo)**, **front-end** e um pouco de **back-end**.

A aplicação funciona como uma **biblioteca virtual**, onde é possível cadastrar e visualizar informações sobre livros.

---

## 📚 Funcionalidades

✅ Cadastro de livros com os seguintes dados:
- Nome do livro  
- Autor  
- Editora  
- Imagem da capa  
- Sinopse  

✅ Exibição dos livros na categoria **"Todos os Livros"**, em formato de **cards**.  

✅ Visualização da sinopse de cada livro dentro de um **modal** ao clicar em *"Sinopse"*.  

✅ **Busca de livros**:
- O usuário digita o nome do livro desejado.  
- Se encontrado, o resultado aparece em um card.  
- Se não encontrado, é exibido um modal avisando que nenhum livro foi localizado.  

---

## 💻 Tecnologias usadas

- ⚡ `ScrollReveal.js` – Animações de entrada dos elementos  
- 🎨 `Bootstrap` – Componentes prontos e responsividade  
- ✨ `JavaScript` – Lógica e manipulação do DOM  
- 🏗️ `HTML` – Estrutura da página  
- 🎨 `CSS` – Estilização personalizada
